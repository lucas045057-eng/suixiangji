# 随想记 V1.0.5（9）更新提示与下载修复报告

日期：2026-10-10。对应反馈：第二台手机 V1.0.4 未自动提示更新，手动检查发现新版本后下载时报 `SocketException: Connection reset by peer`，地址为 `download.suixiangji.icu`。

## 原因与修复

1. 自动提示：应用根状态使用位于 MaterialApp 上方的页面上下文打开弹窗，缺少 MaterialLocalizations / Navigator。回归测试在修复前复现该错误。改为通过 MaterialApp 的 Navigator 打开弹窗；启动断网后回到应用可重新检查，同一进程内抑制并发和重复弹窗。
2. 下载：检查版本走既有 Android Embedded Cronet，APK 下载走 Dart HttpClient。用户错误确认连接在下载阶段被重置。下载器现复用既有平台 HTTP 工厂，Android 使用 Embedded Cronet；继续保留 HTTPS 校验、进度、取消、不完整文件校验和临时文件清理，加入连接/流空闲超时。本机对旧下载域名也存在 TLS / 连接重置，因此服务器把旧客户端收到的下载地址切换至经过完整下载核验的 GitHub 文件。
3. 快速预算编辑：本轮回归暴露同步操作编号仅含时间戳时可能被连续编辑复用。沿用已有随机后缀模式，使新编辑获得独立操作编号；保留原同步和回执持久化流程。

## 用户升级方式

V1.0.4 的启动弹窗错误存在于已安装程序中，服务器无法远程修改这段代码。请进入“我的 → 检查更新”，重新检查以取得新地址，再下载并覆盖安装 V1.0.5（9）。若手机仍显示旧下载域名，应重新检查更新。也可使用本文链接下载同一 APK。保留现有应用，不需要卸载或清除数据。
