## WP-F 共享财务口径

新增小型TransactionQuery公共查询对象，按发生日期筛选/排序，CNY旧记录空快照回退原金额；外币保留可靠快照，未知转换不当作已知0。统计与预算全月总額一致；日均另取截至今日集合。后端assets/insights共用CNY值函数。

数据和复用：复用原交易模型、金额字段、Insights及预算消费集合；不新增汇总库。

共同根因：发生日期与时间戳错位、历史混入、编辑换币带入旧汇率、使用未来报价、旧CNY空快照漏计。

## WP-A 记账与账本

默认CNY及本机常用币种偏好，手动表单/快捷记共用；午饭语料解析真实分类ID及有效默认账户。账本增加搜索/分类与发生日期排序；文字字段提供中文提示并保留组合输入。

数据和复用：FinanceState新增可选本机偏好字段，兼容旧JSON；复用LedgerRepository/LocalStateSession/SyncQueue。偏好明确标为本机设置，不声称跨端同步。

共同根因：演示分类ID在真实用户不存在、归档默认账户误选、编辑换币快照不清除、补记按创建顺序显示。

## WP-B 账户、资产与汇率

账户用途备注、归档/恢复、我的页3个账户预览与可搜索分组管理。公共汇率失败时有日期缓存降级；手动报价仅用户实体。按币种对独立转换并同步账户快照。

数据和复用：Account增加note/archived_at，增量迁移0003；原金额、账户ID、历史账目引用不重建。继续使用账户upsert与原队列，旧客户端缺字段时服务端保留新字段。

共同根因：归档被当作deleted_at又被upsert清空；换算只写本地、服务器旧快照拉回；串行写入和队列状态来源不一致。

## WP-C 统计、预算与首页

可选月份及自定义范围，分类/账户维度；趋势、柱状、占比每次仅显示一个。点击分类/账户进入原账本，返回保留月份。全月总预算及分类分配精确到分；真实昵称/时段问候。

数据和复用：复用已有图表、LedgerPage、Budget实体/API；使用__total__显式总额标识，无第二套预算模型。总额限额不与分类限额相加。

共同根因：三张图同时拥挤、下钻缺少同范围筛选、日均分母与账目不一致、重复创建月总额、首页固定演示人名。

## WP-D 认证与恢复码

已登录验证当前密码生成192位恢复码；服务器仅存PBKDF2哈希。未登录提供用户名/恢复码/新密码，在锁内消费一次并撤销旧登录。生成、保存提示、登录页找回和重置后普通登录入口齐全。

数据和复用：User增加nullable recovery_code_hash，增量迁移0004；复用用户ID、密码哈希、auth_version及原限流。明文仅一次响应，客户端不自动落盘。

共同根因：没有已验证联系方式，不能无凭证找回；防枚举、重放、并发消费和旧会话继续有效。未预存恢复码的账号须先登录配置。

## WP-E 同步、升级及发布验收

原生Drift事务同时保存财务状态和待同步队列，先持久化再发布内存。旧SQLite+离线队列可重开；真实WSL PostgreSQL并发/升级、真实HTTP和两个SQLite客户端同步。版本1.0.5+8，Android原签名覆盖，Windows候选构建/启动。

数据和复用：沿用既有表、JSON键值存储、SyncCoordinator、幂等操作ID和server_version。实际Android/Windows使用Drift；SharedPreferences兼容适配器不声称具备数据库原子性。

共同根因：本地状态写成功而队列失败造成断裂；真实PG并发版本分配/身份缓存测试缺口；发布签名或包名不连续。
