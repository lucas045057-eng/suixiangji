# WealthMate V1 可同步交付计划

## 目标

在现有 Web/PWA 预览和 Flutter 客户端源代码基础上，交付可部署的 FastAPI/PostgreSQL 服务端、可幂等同步的 REST 接口、多币种折算与月度报告接口，并补齐 Flutter 的正式接入基线。

## 实施顺序

1. [ ] 写后端纯领域规则测试：自然语言草稿、转账不计收支、汇率缺失、月度统计、幂等同步。
2. [ ] 实现后端纯领域规则和数据结构。
3. [ ] 实现 FastAPI、SQLAlchemy 模型、JWT、同步、备份、汇率和报告 API。
4. [ ] 写并运行 API/服务层可用测试；若环境缺依赖，保留可运行的纯 Python 测试和阻塞证据。
5. [ ] 扩展 Flutter 模型、API 客户端、本地存储 schema、报告展示和多币种字段。
6. [ ] 运行可用的静态检查与测试，生成手机/Windows/服务器部署文档和验收状态表。

## 验证门槛

- 服务端纯规则测试必须通过。
- Python 依赖可用时运行 API 测试；不可用时不得声称联机通过。
- Flutter/Dart 可用时运行 `flutter analyze`、`flutter test` 和目标平台构建；不可用时明确标记阻塞。
- 最终交付报告列出实际通过项、需要用户配置的项以及当前环境未能执行的项。
