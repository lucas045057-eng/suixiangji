分类候选按交易类型过滤，类型切换会清理不匹配选择；Ledger Store 与后端 CRUD/sync 共用边界校验，转账语义保持独立。

### 3. 双设备同步与会话隔离 — PASS（自动化 fake A/B 场景）

先用同账号、独立本地会话的 A/B fake server 场景复现问题，再按失败位置修复：

- push 返回的服务端 watermark 不再误作 pull 游标，避免 B 跳过 A 已接受的更早变更；
- push 失败时不继续 pull，保留 pending、游标和上次成功同步时间；
- 在途旧请求只能完成仍匹配的 `client_op_id`/实体快照，不能覆盖较新的本地编辑；
- 冲突恢复保护 transactions/accounts/categories/budgets 的较新 pending 操作；
- logout/relogin、重启、JWT gate 与 owner partition 恢复均保留游标和队列边界；
- 迟到的旧账号 push/pull 结果在新账号会话中被丢弃；
- 未物化的新用户分区与已持久化空状态保持 API 兼容，同时首次变更可以正确使用功能初始快照。

未增加同步 payload 字段，未修改 JWT 公共协议，未修改数据库 schema/migration。

涉及：`outputs/wealthmate_flutter/lib/core/sync/sync_coordinator.dart`、`lib/core/database/local_state_session.dart`、`lib/data/finance_repository.dart`、`lib/data/local_repository.dart`、`lib/state/finance_store.dart` 及同步测试。

证据：正式分支同步/P0 专项命令共 `88` 项通过；其中 fake A/B 双设备、同步 coordinator、auth gate、session partition 与生命周期场景均通过，并包含在全量 `318` 项中。
