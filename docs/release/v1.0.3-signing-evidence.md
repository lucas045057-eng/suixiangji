## Inspection method

`tools/inspect-android-signing.ps1` accepts an APK path and an Android SDK path. For an available APK it reports only package name, version name, version code, APK SHA-256, and signing-certificate SHA-256. It accepts no keystore, password, alias, or secret input and returns exit code `2` when the APK or required Android SDK tool is unavailable.

The root `.gitignore` explicitly ignores `**/key.properties`, `**/*.jks`, and `**/*.keystore`; this fix added the rules because the root ignore file previously lacked them.
