# 随想记 Batch 1 真实设备同步验收手册

## 当前状态

- Android：IMPLEMENTED / TESTED；DEVICE VERIFIED = NOT_RUN
- Windows：IMPLEMENTED / TESTED；DEVICE VERIFIED = NOT_RUN
- 本手册需要用户在真实设备上执行后，才能把设备状态改为 PASS。

## 开始前准备

1. 在运行后端的电脑上启动随想记服务。
2. 查看电脑在局域网中的 IPv4 地址，例如 `192.168.1.20`。
3. 手机和电脑连接同一个 Wi-Fi。
4. 手机端配置地址时使用 `http://192.168.1.20:18000`。不要使用 `127.0.0.1` 或 `localhost`。
5. 两台设备使用同一个随想记用户名和密码。

本次已创建专用验收账户：`device_test_batch15`。密码通过当前会话提供，不写入仓库。

## SYNC-01：在线新增

1. 确认手机联网并登录。
2. 新增一笔“在线测试 1 元”，确认入账。
3. 到电脑端登录同一账号并点击同步。
4. 确认电脑端出现同一笔账，金额、分类、账户和日期一致。

结果：`PASS` / `FAIL` / `NOT_RUN`

## SYNC-02：断网连续 10 笔

1. 手机登录后打开飞行模式。
2. 连续新增并确认 1 元到 10 元的 10 笔测试账目。
3. 确认断网期间 10 笔都能在手机账本中看到。
4. 完全关闭随想记，再重新打开，确认 10 笔仍存在。
5. 关闭飞行模式，点击“我的 → 同步状态 → 刷新”。
6. 在电脑端检查服务端，确认恰好新增 10 笔。
7. 再同步一次，确认数量仍然是 10 笔。

结果：`PASS` / `FAIL` / `NOT_RUN`

## SYNC-03：离线修改

1. 联网新增“修改测试 10 元”。
2. 打开飞行模式，修改金额、分类或备注。
3. 确认手机立即显示修改后的内容。
4. 恢复网络并同步。
5. 在电脑端检查最终内容与手机一致。

结果：`PASS` / `FAIL` / `NOT_RUN`

## SYNC-04：离线删除

1. 新增“删除测试 1 元”。
2. 打开飞行模式并删除它。
3. 确认手机不再正常显示。
4. 恢复网络并同步。
5. 确认电脑端也不再正常显示；服务端应是软删除，而不是物理删除。

结果：`PASS` / `FAIL` / `NOT_RUN`

## SYNC-05：重复上传幂等

1. 完成一笔在线记账。
2. 点击同步两次以上。
3. 确认电脑端只有一笔业务记录，账户余额没有重复增加。

结果：`PASS` / `FAIL` / `NOT_RUN`

## SYNC-06：App 重启后队列恢复

1. 打开飞行模式并新增至少一笔账。
2. 完全关闭随想记；Android 可使用“最近任务中划掉”或系统“强行停止”。
3. 重新打开，确认账目仍存在。
4. 恢复网络并同步，确认服务端最终只有一笔。

结果：`PASS` / `FAIL` / `NOT_RUN`

## SYNC-07：新设备全量恢复

1. 设备 A 创建一笔账户、一笔分类、至少一笔账目和一条预算。
2. 确认设备 A 同步完成。
3. 设备 B 安装随想记并登录同一个账号。
4. 等待首次同步完成。
5. 检查设备 B 是否恢复账户、分类、账目和预算。
6. 本批次不包含 Goal/应急金服务器同步，该项记录为 `NOT SUPPORTED YET`。

结果：`PASS` / `FAIL` / `NOT_RUN`

## 后端检查方式

在运行后端的电脑浏览器打开：

```text
http://电脑IP:18000/health
```

看到 `status: ok` 只代表服务运行，不代表同步通过。最终应以电脑端能看到手机数据、重复同步不重复、离线恢复不丢数据、不同用户互相看不到数据为准。
